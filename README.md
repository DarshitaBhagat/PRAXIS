--AI Bicep Curl Counter--

A real-time AI-powered bicep curl counter built using Streamlit, OpenCV, and MediaPipe.

It uses webcam feed to track elbow joints and counts reps based on shoulder-elbow-wrist angle.

--Features--

Live webcam feed inside a web app

Human pose detection using MediaPipe

Automatic bicep curl counting

--Shows--

Current elbow angle

Total reps

--Tech Stack--

Python

Streamlit

OpenCV

MediaPipe

NumPy
